# Employee Payroll & Workforce Management System Using SQL

## Project Overview

This project is a database-driven Employee Payroll and Workforce Management System developed using MySQL. It manages employee records, departments, payroll processing, attendance tracking, leave requests, project assignments, and reporting.

## Modules

* Department Management
* Employee Management
* Payroll Management
* Attendance Management
* Leave Management
* Project Management

## Database Tables

1. Department
2. Employees
3. Payroll
4. Attendance
5. Leave Request
6. Project
7. Employee Project

## SQL Concepts Used

* DDL Commands
* DML Commands
* Primary Keys
* Foreign Keys
* WHERE Clause
* ORDER BY
* Aggregate Functions
* GROUP BY
* HAVING
* JOINS
* Subqueries
* Views
* Indexes

## Reports Generated

* Employee Directory Report
* Department-wise Employee Count Report
* Department-wise Salary Report
* Highest Paid Employee Report
* Employees Above Average Salary Report
* Attendance Summary Report
* Leave Management Report
* Employee Project Assignment Report
* Project Status Report
* Department-wise Average Salary Report
